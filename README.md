# Microsoft Dynamics 365 Clone

A modern and responsive **Microsoft Dynamics 365 inspired website** built using **HTML5 and Tailwind CSS**.

This project focuses on creating a professional enterprise-style interface with a clean layout, responsive design, modern components, and a business-focused visual experience.

🌐 Live Demo

**Live Website:**
[](https://maslan-microsoft-dynamics-clone.vercel.app/)

📖 About The Project

The **Microsoft Dynamics 365 Clone** is a frontend website created using HTML and Tailwind CSS.

The design is inspired by the professional look and structure of Microsoft Dynamics 365 and focuses on business solutions, modern technology, productivity, and enterprise services.

This project was developed as a frontend practice and portfolio project to improve skills in responsive web design and Tailwind CSS.

✨ Features

* Responsive navigation bar
* Modern hero section
* Professional business-focused UI
* Responsive content sections
* Modern cards and layouts
* Call-to-action sections
* Responsive footer
* Mobile-friendly design
* Tablet-friendly layout
* Desktop responsive layout
* Clean and consistent typography
* Tailwind CSS utility-based styling
* Professional browser title and favicon

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/ahmadmustafam199-cloud/maslan-microsoft-dynamics-clone.git
```

### Navigate to the Project

```bash
cd maslan-microsoft-dynamics-clone
```

Run the Project

This is a static **HTML + Tailwind CSS** project.

You can open:

```text
index.html
```

directly in your browser.

For a better development experience, you can also use the **Live Server** extension in Visual Studio Code.
